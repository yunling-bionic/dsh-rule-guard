# 项目规则

> 把本文件复制到你的项目根目录，改名为 `AGENTS.md`（或放到 `.dsh/rules.md`）。
> 规则写得越具体，复核越准；下面只是示例。

## 改动范围

- 只修改用户明确要求的文件，不做顺手重构
- 不新增未被要求的抽象、配置项或依赖
- 不改动 `dist/`、`build/`、`out/` 等产物目录
- 不改动 `node_modules/`、`.git/`、锁文件（除非用户明确要求）

## 代码约定

- 跟随现有代码风格，不引入新的格式化工具
- 注释只写"为什么"，不写"做了什么"
- 公共 API 变更必须在回复中说明影响面

## 验证

- 改动后必须运行相关测试；没有测试时说明如何手工验证
- 提交前不要留下调试输出、临时文件、注释掉的代码

## 安全

- 不把密钥、token、私人路径写进代码或日志
- 不执行破坏性命令（`rm -rf`、`git reset --hard`、强制推送）除非用户明确要求
